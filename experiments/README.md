# 后续学生实验

[中文](README.md) | [English](README.en.md)

本目录暂不包含已启动的学生实验。

讨论中的比较为：A 仅 workflow/skills；B 在 A 上加入相同案例的结论；C 在 A 上加入相同案例的过程。使用同一批案例与相近的上下文额度，记录实际注入内容及阅读开销。固定学生模型、目标、起始代码、工具权限和预算；教师最终代码是否可读要单独记录，否则无法区分过程学习与实现复用。

无 trace 组的工作目录不能直接检索本案例库。学生任务优先与教师目标区分；多次独立运行才是重复实验，不能把同一教师 run 的 45 个相互依赖案例算成 45 个独立样本。

后续每轮保存实际启动 prompt、选入案例、目标与版本、可见材料、预算/实际成本，以及符合数值要求的端到端结果、达到结果的耗时和无效尝试。不要在未开展实验前预设增益。
