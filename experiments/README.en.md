# Future student experiments

[中文](README.md) | [English](README.en.md)

This directory does not yet contain a launched student experiment.

The proposed comparison is A: workflow/skills only; B: A plus conclusions from the same cases; C: A plus the process from those cases. Use the same case set and comparable context allowances, recording the material actually supplied and its reading cost. Hold student model, target, starting code, tool access and budget fixed. Record access to the teacher’s final implementation separately, or process learning cannot be distinguished from implementation reuse.

The no-trace condition must not be able to search this case repository from its work directory. Prefer student targets that differ from the teacher target. Repetition means independent runs, not treating 45 dependent cases from one teacher run as 45 independent samples.

For each future run, save the actual starting prompt, selected cases, target and revisions, visible material, budget/actual cost, valid end-to-end results, time to obtain them and ineffective attempts. Do not assume an improvement before conducting the experiment.
